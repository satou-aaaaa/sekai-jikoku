# 世界の時刻

「東京が午後3時のとき、ロンドンは何時？」を、時計を進めたりもどしたりして当てる1日5問のゲームです。時差・サマータイム・日付変更線が、遊ぶうちに身につきます。

- 遊ぶ：<https://satou-aaaaa.github.io/sekai-jikoku/>
- 今日の5問はだれでも同じで1日1回。とことん・練習は何度でも遊べます。時間制限はありません。
- 記録は遊ぶ人のブラウザの中だけに残り、外へは送りません。

## データの出どころ

- 町ごとの時刻の決まり（UTC との差・サマータイム）：IANA タイムゾーン・データベース（パブリックドメイン、2026f 版で確かめた） <https://www.iana.org/time-zones>
- 日本標準時：情報通信研究機構（NICT） <https://www.nict.go.jp/sts/jst.html> 、国立天文台 暦Wiki「標準時」
- サマータイム：EU 指令 2000/84/EC、アメリカ国立標準技術研究所（NIST）
- 地図の陸の形：Natural Earth 1:110m Land（パブリックドメイン） <https://www.naturalearthdata.com/>

2026年11月の時点の決まりで作っています。旅行や仕事で時刻を確かめるときは、そのときの公式の情報を見てください。
